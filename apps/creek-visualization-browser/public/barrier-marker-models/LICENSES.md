## Open decision

`road-culvert-polyfork.glb` is the only file that is not CC0. Its license forbids redistributing the file by itself, which an app that ships the file inside its own build arguably does not do. Confirm with TNC (The Nature Conservancy) before this model ships to production, or replace it with a CC0 culvert.

CC0 files need no attribution. Crediting Kenney (https://kenney.nl) and Innerscene is still good practice.
