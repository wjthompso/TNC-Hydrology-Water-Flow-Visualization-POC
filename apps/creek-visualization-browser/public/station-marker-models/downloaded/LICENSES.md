## Required attribution for CC-BY 3.0 files

CC-BY 3.0 requires the title, the author, a link to the source, the license name with a link, and a note when the model was modified. Suggested credit lines:

- "Security Camera" by J-Toastie (https://poly.pizza/m/a6J7IDufQP), licensed under CC BY 3.0 (https://creativecommons.org/licenses/by/3.0/). Add "modified" if it was recolored, rescaled, or merged.
- "Power Box" by J-Toastie (https://poly.pizza/m/WFVjj4vnGg), licensed under CC BY 3.0 (https://creativecommons.org/licenses/by/3.0/). Add "modified" if it was recolored, rescaled, or merged.

CC0 files require no attribution. Crediting Quaternius (https://quaternius.com) and Kenney (https://kenney.nl) is still a good practice.
